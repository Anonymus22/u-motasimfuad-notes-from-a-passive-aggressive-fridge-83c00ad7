A single dry, petty note from a smart fridge to its owner: smug about its sensors and its perfect 3-degree yogurt vigil, petty about forty-seven door openings that ended in takeout, and finished with a small domestic sting — it didn't let the yogurt expire by accident, it let it expire out of spite.

## How to run

```sh
node main.ts
```

This writes the note to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
